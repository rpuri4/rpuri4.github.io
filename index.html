02 / WHAT I'VE BEEN BUILDING

Distributed Log Storage Engine

A replicated log built in C++ using Raft to keep data consistent across machines. I worked on how nodes agree on writes, store them efficiently, and recover when a node fails.

Agent Evaluation Harness

A Python toolkit for testing whether LLM agents complete tasks and use their tools correctly. It captures traces of each run to help pinpoint failures and understand where time is spent.

Concurrent Task Orchestrator

A distributed task scheduler in Go that coordinates work across multiple workers. It handles retries, worker crashes, and backpressure so jobs keep moving under load.
